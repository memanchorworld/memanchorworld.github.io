Abstract

Sparse world models for 4D semantic occupancy forecasting represent scenes with a small set of evolving queries to efficiently predict future geometry and semantics for autonomous driving. However, existing sparse world models face a bottleneck in using historical temporal evidence for long-horizon forecasting. They rely on scene states to carry historical information implicitly, allowing errors to propagate and accumulate across successive forecasting steps and causing geometric and semantic deviations. To address this limitation, we present MemAnchorWorld, a sparse occupancy world model that explicitly retrieves relevant historical geometric and semantic evidence for 4D semantic occupancy forecasting. Inspired by the von Restorff effect, we introduce a forecast-time-conditioned hierarchical dual-path memory-anchor retrieval mechanism. Guided by the effective age and semantic compatibility of historical information, it combines query-level candidate selection with point-level memory-anchor retrieval to provide historical evidence for sparse points at different forecast times. To better use memory anchors and existing features, a point-level residual adapter jointly gated by the task and forecast time separately controls residual corrections to semantics, occupancy confidence, and spatial positions. On Occ3D-nuScenes, MemAnchorWorld achieves an average mIoU of 13.55% and an average IoU of 22.84% across the 1–3 s forecasting horizons, attaining state-of-the-art performance on both metrics. Project page: https://recall-world.github.io/.

Method Overview

MemAnchorWorld retrieves memory anchors to refine sparse future predictions and produce 4D semantic occupancy.

The perception backbone first encodes surround-view images into a sparse scene state Z0. Conditioned on the ego state, the forecasting backbone recurrently updates scene queries to generate predictions Bh at each forecast horizon.

The forecast-time-conditioned hierarchical dual-path memory-anchor retrieval module constructs a historical memory bank 𝓜 from queries in earlier frames. Before retrieval at each forecast horizon, it uses ego poses to align historical points in a common coordinate frame, then applies object motion compensation to extrapolate them to the target forecast time. Using the corresponding scene queries and predicted points as retrieval cues and conditioned on the forecast-time embedding, the module considers historical age, semantic reliability, and geometric–semantic relevance. It first selects candidate historical queries through geometric–semantic dual-path coarse retrieval, then performs point-level memory-anchor retrieval among their associated points and aggregates the retrieved features and semantics as correction evidence.

Finally, the point-level residual adapter jointly gated by task and forecast time fuses the retrieved evidence with the current prediction representation and forecast-time information. It generates separate residual corrections for semantics, occupancy confidence, and spatial position, with independent gates modulating the strength of each correction. Sparse occupancy decoding converts the corrected point-level outputs into semantic occupancy grids Ŷh at each forecast horizon.

At 1, 2, and 3 s, we evaluate historical complementarity (Hist. compl.), correction of wrong base predictions with correct history (WC), and retention of correct base predictions with wrong history (CW). Metric definitions are provided in Appendix C.4.

Complementary Historical Evidence. Table 3 reports rates of 25.25%, 24.29%, and 23.19% at the three horizons, respectively. Thus, roughly one quarter of currently misclassified points can retrieve semantically correct memory anchors from history, providing complementary semantic evidence for refining future point-level predictions.

Use of Complementary History. Among points with an incorrect base prediction but a correct historical class, the adapter corrects 9.57%, 11.12%, and 12.58% at 1, 2, and 3 s, respectively. The correction rate increases with the forecast horizon. These results show that the adapter can use correct retrieved historical semantics to guide residual corrections, recovering the correct class for some initially misclassified points and translating complementary evidence into effective prediction refinement.

Resistance to Conflicting History. When the base prediction is correct but the historical class is wrong, 97.47%, 97.19%, and 96.64% of points remain correct after adaptation at 1, 2, and 3 s, respectively. These results support the effectiveness of the gated adapter in selectively fusing historical evidence, limiting interference from erroneous history while preserving initially correct point-level predictions under semantic conflicts.

Table 4 reports ablation results for the core components using average mIoU and IoU over the 1–3 s forecasts. SparseWorld serves as our baseline, achieving average mIoU and IoU scores of 13.20% and 22.03%, respectively. When only memory-anchor retrieval is added, ordinary feature fusion replaces gated fusion. Average mIoU and IoU improve over the baseline by 0.04 and 0.22 percentage points, respectively, indicating that retrieved memory anchors provide historical evidence that improves future predictions.

When only task–horizon gated adaptation is added, an MLP encodes queries at the target forecast horizon in place of the memory-anchor retrieval branch. Average mIoU and IoU improve over the baseline by 0.11 and 0.31 percentage points, respectively. These gains indicate that task–horizon gated adaptation can use the current prediction representation for adaptive correction, reducing the impact of error propagation and accumulation on future predictions. With both components fully enabled, average mIoU and IoU reach 13.55% and 22.84%, respectively, outperforming both single-component variants.
